# UCF_C
UCF_C is the C (and better) version of [UCF](https://github.com/fif3x/UCF)

# Installation

1. To install the files, you can either download through [GitHub](https://github.com/fif3x/UCF_C) or through Git

```bash
git clone https://github.com/fif3x/UCF_C
```

2. Navigate to the `build/` folder, and execute the needed file.

For Windows:
```bash
build
```

For Linux:

```bash
./dependencies.sh
./build.sh
```
_Note: the dependencies script is made for Debian-based distros, you may need to modify to fit your needs_

3. Navigate to the `bin/` folder to run the binary
